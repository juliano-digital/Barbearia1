Resumo do projeto
A Barbearia Brasa é um site responsivo de apresentação e agendamento para uma barbearia. Ele permite que o cliente conheça os serviços, escolha data e horário, informe nome e telefone e consulte o comprovante. Também tem uma área de agenda, um chat simples de protótipo e um atalho para buscar a barbearia no Google Maps.

Funcionalidades
Página de apresentação da barbearia e dos serviços, com preços e duração.
Agendamento de serviços com horários em intervalos de 30 minutos; horários ocupados aparecem como reservados.
Comprovante do agendamento e consulta do histórico do cliente.
Painel da barbearia com lista de agendamentos, filtros e motivo dos cancelamentos.
Chat de protótipo que responde somente sobre a localização, o funcionamento e a proposta da barbearia.
Atalho flutuante “Nos avalie”, com cinco estrelas, que abre uma busca no Google Maps.
Tecnologias usadas
React e TypeScript — interface e lógica do site.
Vite — desenvolvimento local e geração da versão de produção.
Supabase — banco PostgreSQL, autenticação, consulta da agenda e atualizações em tempo real.
React Router — navegação entre páginas.
Tailwind CSS e CSS próprio — estilos e layout responsivo.
date-fns e React Day Picker — datas e calendário.
Framer Motion e GSAP — animações.
Lucide React — ícones.
Node.js e npm — instalar dependências, executar localmente e compilar o projeto.
Observações para publicação
O chat é apenas um protótipo: não usa inteligência artificial e responde a um conjunto limitado de assuntos. Endereço e telefone no site são fictícios e devem ser substituídos pelos dados reais. Além disso, a agenda pública atualmente exibe nome e telefone dos clientes; vale avaliar essa exposição antes de publicar
